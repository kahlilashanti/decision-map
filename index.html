⚖️ The Verdict
How to use
  • Drag cards to move them. Drag empty space to pan.
  • Double-click a card to edit its text.
  • Select a card, then add a Pro, Con, Option or Note. It links automatically.
  • Click a ★ badge to change a pro or con weight (1 to 5).
  • Selected card: change type, Connect, Duplicate, or Delete.
  • Click an arrow to add Yes / No labels, flip it, or delete it.
  • Delete key removes the selection. Esc cancels.
  • Verdict scores each Option: pro weights minus con weights.
  • Everything saves in this browser. Use Export to back up.
